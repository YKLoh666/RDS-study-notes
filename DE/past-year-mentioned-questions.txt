Chapter 5
- What is data streaming? Why is it important?
- Batch Processing vs Stream Processing
- Types of Streaming
  - Real-time streaming: Process data with minimal delay, high frequency, time-sensitive applications, such as financial transactions and fraud detection
  - Near real-time streaming: Process data with moderate delay, less time-sensitive applications, such as user behavior analysis and monitoring systems
  - Event Streaming: Continuous flow of data generated by events, such as user interactions, sensor readings, and system logs. Processed by event stream processing platforms like Apache Kafka
  - Batch streaming (Micro-batch processing): Higher latency, from seconds to minutes, used for applications that can tolerate some delay, such as ETL pipelines and user activity aggregation over short intervals (e.g., every 5 minutes)
