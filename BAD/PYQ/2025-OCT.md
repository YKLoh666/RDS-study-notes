## Question 1

a)

i)

- Blockchain is decentralised compared to traditional centralised systems, which means there is no central authority controlling the network. This improves the transparency of the system, as no single entity can manipulate the data or transactions on the blockchain.
- Decentralisation also improves availability, as the data is distributed across multiple nodes in the network, making it more resilient to failures or attacks and improves real time traceability. In a centralised system, if the central server goes down, the entire system can become unavailable.

ii)

- All blocks in blockchain are chained by cryptographic hashing, altering a block will break the chain and make it quickly detectable. This prevent tampering and ensures the integrity of the data stored on the blockchain.
- Cryptographic hashing also used to sign transactions, making it difficult for attackers to forge transactions or manipulate the data on the blockchain without being detected. This improves the security of the system and ensures that only valid transactions are recorded on the blockchain.

iii)

- Consortium is more scalable than public blockchain, as it control the size of the network and the number of nodes that can participate in the consensus process. Reducing the number of nodes can improve the speed and efficiency of the network, as there are fewer nodes to validate transactions and reach consensus. On the other hand, public blockchain is open to anyone, which can lead to a larger number of nodes and slower transaction processing times, especially product traceability system which can produce a large number of transactions that need to be validated and recorded on the blockchain.
- Consortium blockchain has more privacy than public blockchain, as it restricts access to the network and the data stored on the blockchain. This can be important for product traceability systems, where sensitive information about the products and their supply chain may need to be kept confidential. Public blockchain, on the other hand, is open to anyone, which can make it more difficult to protect sensitive information.

b) DEX is an decentralized cryptocurrency exchange platform.

i)

- Ethereum main net has a very low transaction throughput, which is not suitable for DEX which has thousands of transactions per hour. Using Layer 2 solution can process the transactions off-chain and only settle the final state on the main chain, which can significantly increase the transaction throughput.
- Processing transactions on main net can be expensive due to high gas fees, as it is charged for every transaction and smart contract execution. Using Layer 2 solution can reduce the gas fees by batching multiple transactions together and only settling the final state on the main chain, which can significantly reduce the cost of using the DEX.
- Using Ethereum main net also create worse user experience, as it can take longer for transactions to be confirmed and settled on the main chain. Using Layer 2 solution can provide near-instant transaction confirmation and settlement, creating seamless user experience simi

ii)

- ZK-Rollup is more suitable for DEX than Optimistic Rollup, as it provides faster transaction finality and lower latency. ZK-Rollup uses zero-knowledge proofs to validate transactions off-chain, which allows for faster processing and confirmation times compared to Optimistic Rollup, which relies on a challenge period for fraud proofs.
- ZK-Rollup also provides better security guarantees, as it uses cryptographic proofs to ensure the validity of transactions, while Optimistic Rollup relies on the assumption that most participants are honest and will not submit fraudulent transactions. This can make ZK-Rollup more secure and resistant to attacks compared to Optimistic Rollup.
- ZK-Rollup can also provide better scalability, as it can handle a larger number of transactions per second compared to Optimistic Rollup, which can be limited by the challenge period and the need for participants to monitor the network for fraudulent transactions. This can make ZK-Rollup more suitable for high-volume applications like DEX, where fast and efficient transaction processing is critical.

- Oracle services can be used in DEX to provide external data feeds, such as price feeds for cryptocurrencies from different exchanges or market data for other assets. This helps to detect and prevent price manipulation or arbitrage opportunities, as the DEX can use the oracle data to ensure that trades are executed at fair market prices.
